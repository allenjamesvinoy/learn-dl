Step 1 of 5
The Data
Every deep learning problem starts with data. Here we have 20 observations where each input x has a corresponding output y. The relationship is approximately y ≈ 2x + 1, but with real-world noise added.

In PyTorch, data lives in Tensors — efficient multi-dimensional arrays that support automatic differentiation. A DataLoader handles shuffling and batching during training.
  dataset.py
import torch
from torch.utils.data import (
    TensorDataset, DataLoader
)

# Raw observations (x, y = 2x + 1 + noise)
X = torch.tensor([-1.9, -1.6, ..., 1.8])
y = torch.tensor([-2.49, -2.44, ..., 4.32])

# Wrap for mini-batching later
dataset = TensorDataset(
    X.unsqueeze(1),
    y.unsqueeze(1)
)
loader = DataLoader(
    dataset,
    batch_size=5,
    shuffle=True
)
20 training samples — the relationship is noisy but learnable

The Model
A linear model has two learnable parameters: a weight w and a bias b. It predicts ŷ = w·x + b.

Use the sliders to move the line. Notice how changing w changes the slope, and b shifts it up or down. The goal of training is to find the w and b that fit the data best.

The Loss Surface
The loss function measures how wrong the model is — lower is better. For regression we use Mean Squared Error: average of squared residuals.

The loss surface (right) shows the loss value for every possible (w, b) pair — x-axis is the weight, y-axis is the bias. Click anywhere on the loss surface to jump there and watch the data plot update instantly. The white cross marks the optimal parameters where loss is minimized.
  loss.py
import torch.nn as nn

criterion = nn.MSELoss()

# Forward pass

loss   = criterion(y_pred, y.unsqueeze(1))

# Loss = (1/N) · Σ (ŷᵢ − yᵢ)²

The Gradient
The gradient is a vector of partial derivatives — it points in the direction of steepest increase of the loss. We move in the opposite direction, scaled by the learning rate η, to reduce the loss.

  backward.py
# Zero out old gradients first
model.zero_grad()

# Forward pass
y_pred = model(X.unsqueeze(1))
loss   = criterion(y_pred, y.unsqueeze(1))

# Backward pass: compute ∂L/∂w, ∂L/∂b
loss.backward()

gw = model.weight.grad  # ∂L/∂w
gb = model.bias.grad    # ∂L/∂b

# Gradient descent step (manual)

    model.weight -= lr * gw
